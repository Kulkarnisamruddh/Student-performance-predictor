# Dataset

Download the Student Performance dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/320/student+performance).

Extract the archive and put `student-mat.csv` in this folder.

The raw CSV is excluded from Git by `.gitignore`. The file uses a semicolon (`;`) as the delimiter.

Dataset citation: Cortez, P. (2008). *Student Performance* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T
